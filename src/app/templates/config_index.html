Telegram

Dein direkter Draht zum Server

Wird geladen

Nur diese Personen dürfen den Bot steuern. Starte den Bot in Telegram mit /start.

Woher bekomme ich den Token?
  1. Öffne @BotFather in Telegram.
  2. Sende /mybots und wähle deinen Bot.
  3. Öffne API Token und kopiere den Wert hier hinein.

Für einen neuen Bot verwende /newbot. Den bestehenden Token nur erneuern, wenn das nötig ist: Der bisherige Bot verliert dann seine Anmeldung.

Discord

Steuerung im privaten Kanal

Wird geladen
Token und IDs finden
  1. Öffne das Discord Developer Portal und wähle deine Anwendung.
  2. Unter Bot findest du die Token-Einrichtung. Verwende deinen vorhandenen Token. Reset Token macht den alten ungültig.
  3. Die Anwendungs-ID steht unter General Information → Application ID.
  4. Aktiviere in Discord Einstellungen → Erweitert → Entwicklermodus. Kopiere Benutzer-, Server- und Kanal-ID per Rechtsklick.

Der Bot braucht Zugang zu deinem privaten Textkanal und die Bereiche bot und applications.commands bei der Einladung. Administratorrechte und privilegierte Intents sind nicht nötig.

OpenAI

Antworten, Diagnosen und Pläne

Wird geladen
API-Schlüssel erstellen
  1. Öffne OpenAI → API keys und wähle dein Projekt.
  2. Erstelle mit Create new secret key einen Schlüssel.
  3. Kopiere ihn direkt in dieses Feld. Er wird später nicht erneut angezeigt.

Ein ChatGPT-Login ersetzt hier keinen API-Schlüssel. Ohne Schlüssel bleiben Statusabfragen und freigegebene Aktionen verfügbar. Prüfe die KI anschließend mit /ki.

Healthchecks

Externe Warnung bei einem Ausfall

Wird geladen
Wo finde ich die Ping-URLs?
  1. Öffne deine Healthchecks-Übersicht.
  2. Verwende je einen Check für den Server und den Telegram-Bot.
  3. Kopiere jeweils die Ping URL in das passende Feld. Die Browseradresse der Detailseite ist nicht die Ping-URL.

Unterstützt werden UUID-Ping-URLs von hc-ping.com. Ein Management-API-Schlüssel ist nicht nötig. Die Lebenszeichen kommen jede Minute; vier Minuten Schonfrist passen zur bisherigen Einrichtung. Beim Speichern wird kein Test-Ping gesendet.
