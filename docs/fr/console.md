# Console SSH : lire l’activité

Fonctions et commandes · 1.3.0.0

1. La console SSH est une vue d’activité en lecture seule, pas un shell interactif. Elle affiche les phases de l’IA depuis le dernier redémarrage du bot et les tâches récentes. Questions, réponses et tokens sont exclus.

2. La progression APT provient uniquement de lignes connues et des paquets du vrai plan. Les sorties brutes des scripts sont exclues. Les heures de création sont indiquées ; aucun horaire n’est inventé. Sans adaptateur, la page reste avec une explication.
