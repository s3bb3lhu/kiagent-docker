# Telegram : token et identifiant utilisateur

Paramètres et connexions · 1.4.0.0

1. Ouvrez BotFather via le lien officiel. Utilisez /newbot pour créer un bot ou /mybots pour choisir un bot existant et gérer son token. Saisissez-le uniquement dans l’installateur ou Paramètres → Telegram.

2. Saisissez l’identifiant Telegram personnel numérique, pas le @pseudo. Il correspond à user.id ou from.id d’une mise à jour privée vous appartenant. Pour une installation neuve, l’administrateur peut l’obtenir via la Bot API avant le polling ; n’utilisez pas getUpdates en parallèle du bot actif.

3. Démarrez le bot dans un chat privé puis testez /status. Seuls les utilisateurs autorisés en privé sont acceptés. Un champ vide conserve le token enregistré. Remplacez un token divulgué dans BotFather puis mettez-le à jour ici.
