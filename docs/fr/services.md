# Services, Docker et thèmes

Fonctions et commandes · 1.5.0.0

1. Une nouvelle installation complète inclut la gestion HTTPS sur 9898 et le portail de services sur 9999. Les ports occupés sont préservés ; les adresses figurent dans .installation. Créez identifiant et mot de passe dans chaque interface. Aucun jeton requis.

2. Les services et conteneurs actifs ou arrêtés sont détectés automatiquement. Démarrer, arrêter et redémarrer exigent le nom de la cible. Un arrêt critique peut couper l’accès. Aucun résultat incertain n’est relancé automatiquement.

3. Les sites des conteneurs proposent des boutons pour les ports TCP publiés ; un port ne garantit pas un site web. Choisissez séparément thème, couleur, logo et bouton. Le mode jour/nuit a son interrupteur. Les choix sont conservés dans ce navigateur.
