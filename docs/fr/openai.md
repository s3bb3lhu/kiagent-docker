# OpenAI : clé API et IA

Paramètres et connexions · 1.1.0.0

1. Ouvrez API keys, choisissez votre projet et créez une clé secrète. Saisissez-la directement dans Paramètres → OpenAI. Vérifiez les autorisations, l’accès au modèle et la facturation du projet. N’envoyez jamais d’identifiants dans un chat.

2. La clé est facultative. État et actions directes confirmées restent disponibles sans elle. Un champ vide conserve la clé ; l’option explicite la supprime. Les clés enregistrées ne sont pas renvoyées au navigateur.

3. /ki envoie la demande et des mesures prédéfinies à OpenAI. N’incluez aucun secret. Les demandes d’installation préparent un vrai plan APT ; le texte de l’IA n’est jamais exécuté dans un shell. Une confirmation distincte autorise l’installation.

- [Clés API OpenAI](https://platform.openai.com/api-keys)
- [OpenAI : exploitation sûre](https://developers.openai.com/api/docs/guides/production-best-practices)
