# OpenAI: API-Schlüssel & KI

Einstellungen & Verbindungen · 1.2.0.0

1. Die API-Key-Seite öffnen, eigenes Projekt wählen und einen neuen geheimen Schlüssel erstellen. Den Schlüssel unmittelbar unter Einstellungen → OpenAI einfügen. Nutzungsberechtigung, Modellzugang und Abrechnung des eigenen API-Projekts prüfen. Keine Zugangsdaten im Chat senden.

2. Der Schlüssel ist optional. Ohne ihn bleiben Status und direkte bestätigte Paketaktionen verfügbar. Leeres Feld behält den bisherigen Wert; die ausdrückliche Löschoption entfernt ihn. Gespeicherte Schlüssel werden nicht an den Browser zurückgegeben.

3. /ki sendet Auftrag und feste Statusmesswerte an OpenAI. Keine Geheimnisse in Fragen eingeben. Bei Installationswünschen wird ein echter APT-Plan vorbereitet; KI-Text wird niemals als Shell-Befehl ausgeführt. Erst eine eigene Bestätigung erlaubt die Installation.
