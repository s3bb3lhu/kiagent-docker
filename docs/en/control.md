# Commands and server restart

Features and control · 1.3.0.0

1. Telegram: /status, /ram, /disk, /uptime and /diagnose read status or prepare an AI diagnosis. /ki answers questions or plans installs. Discord provides /status, /ki, /ki_install, /ki_install_status and automation commands. The bots do not have identical command sets.

2. Control offers read-only queries, confirmed RAID-monitor repair, automation switches, practice/confirmation tests and package installation. Cancel does not perform a repair. The practice service is not a production application service.

3. Server restart affects the whole host. A fixed restart request with about ten seconds delay is created only after confirmation and typing the displayed word. Bots and website temporarily go offline. A requested restart does not confirm completion.
