# Status, CPU cores and appearance

Features and control · 1.5.0.0

1. Status shows host CPU, every logical core, RAM, uptime, disks, filesystems, network rates and assigned IP addresses. Visible tabs update every three seconds. CPU and network rates need two samples; lost connections mark readings stale.

2. The header shows local time and separate server time with its timezone. Choose Ruby Control or Crimson Glass, each in red/blue/green/purple/anthracite and light/dark. Collapse the menu and choose a language at bottom left. Preferences are saved for this browser.
