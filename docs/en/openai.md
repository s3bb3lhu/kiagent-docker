# OpenAI: API key and AI

Settings and connections · 1.3.0.1

1. Open the API keys page, choose your project and create a new secret key. Enter it directly in Settings → OpenAI. Check your API project’s permissions, model access and billing. Never send credentials in chat.

2. The key is optional. Status and direct confirmed package actions remain available without it. An empty field keeps the current key; the explicit removal option deletes it. Saved keys are not returned to the browser.

3. /ki sends the request and fixed status readings to OpenAI. Do not include secrets in questions. Installation requests prepare a real APT plan; AI text is never executed as a shell command. A separate confirmation authorizes installation.

- [OpenAI API keys](https://platform.openai.com/api-keys)
- [OpenAI production guidance](https://developers.openai.com/api/docs/guides/production-best-practices)
