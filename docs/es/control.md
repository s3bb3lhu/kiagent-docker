# Comandos y reinicio del servidor

Funciones y control · 1.4.0.0

1. Telegram: /status, /ram, /disk, /uptime y /diagnose consultan estado o crean diagnóstico de IA. /ki responde o planifica instalaciones. Discord ofrece /status, /ki, /ki_install, /ki_install_status y automatización. Los bots no tienen comandos idénticos.

2. Control ofrece consultas de lectura, reparación confirmada del monitor RAID, automatización, pruebas y paquetes. Cancelar no ejecuta reparación. El servicio de práctica no es una aplicación productiva.

3. Reiniciar servidor afecta a todo el host. Solo se programa tras confirmar y escribir la palabra indicada, con unos diez segundos de demora. Bots y web quedan temporalmente sin conexión. Solicitar reinicio no confirma que haya terminado.
