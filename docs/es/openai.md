# OpenAI: clave API e IA

Ajustes y conexiones · 1.0.0.1

1. Abre API keys, elige tu proyecto y crea una clave secreta nueva. Introdúcela directamente en Ajustes → OpenAI. Revisa permisos, acceso al modelo y facturación del proyecto. Nunca envíes credenciales por chat.

2. La clave es opcional. Estado y acciones directas confirmadas siguen disponibles sin ella. Un campo vacío conserva la clave; la opción explícita la elimina. Las claves guardadas no se devuelven al navegador.

3. /ki envía la solicitud y mediciones fijas a OpenAI. No incluyas secretos. Las solicitudes de instalación preparan un plan APT real; el texto de IA nunca se ejecuta como shell. La instalación necesita confirmación aparte.

- [Claves API de OpenAI](https://platform.openai.com/api-keys)
- [OpenAI: uso seguro](https://developers.openai.com/api/docs/guides/production-best-practices)
