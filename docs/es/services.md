# Servicios, Docker y diseños

Funciones y control · 1.5.0.0

1. La instalación completa incluye el control en HTTPS 9898 y el gestor en 9999. No se ocupan puertos ajenos; las direcciones quedan en .installation. Crea usuario y contraseña en cada interfaz. No se necesita token de instalación.

2. Se detectan servicios y contenedores activos o detenidos. Iniciar, detener y reiniciar requieren confirmar el nombre. Detener servicios críticos puede cortar el acceso. Los resultados inciertos no se reintentan.

3. Las webs de contenedores muestran botones para puertos TCP publicados; un puerto no garantiza una web. En Diseño elige por separado estilo, color, logo y botón. Hay un interruptor día/noche. Se guarda en ese navegador.
