# Consola SSH: consultar actividad

Funciones y control · 1.4.0.0

1. La consola SSH es una vista de actividad de solo lectura, no un terminal interactivo. Muestra fases de IA desde el último reinicio del bot y tareas recientes. Excluye preguntas, respuestas y tokens.

2. El progreso APT se extrae solo de líneas conocidas y paquetes del plan real. No muestra salida bruta de scripts. Las horas de creación se etiquetan; no inventa horas para pasos sin marca. Sin adaptador la página mantiene una explicación.
